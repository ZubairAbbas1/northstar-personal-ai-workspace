# Screenshots & Demo Assets Guide

This directory stores sanitized demonstration screenshots for public presentation.

> **Privacy Warning**: Never commit screenshots containing sensitive real personal email addresses, private calendar events, or confidential project credentials. Use sanitized demo data.

---

### Required Demo Captures

1. **`dashboard_overview.png`**
   - Executive command center showing today's meetings, action-required tasks, and KPI metric cards.

2. **`smart_inbox.png`**
   - Smart Inbox triage displaying categorized emails (`[URGENT]`, `[ACTION NEEDED]`, `[FYI]`) with reasoning and suggested next actions.

3. **`morning_brief.png`**
   - Daily morning briefing combining chronological schedule, attention items, and suggested deep work focus blocks.

4. **`meeting_prep.png`**
   - Meeting preparation briefing showing attendees, purpose, recent email context, outstanding decisions, and questions worth asking.

5. **`what_should_i_do_next.png`**
   - The signature deterministic priority recommendation view displaying score breakdown (e.g. `91 / 100`) and time slot fit.

6. **`follow_up_radar.png`**
   - Follow-up radar showing `NEEDS YOUR REPLY` vs `WAITING ON THEM` tables.

7. **`universal_search.png`**
   - Multi-source search results synthesized across Gmail, Calendar, Tasks, and ChromaDB document vault.

8. **`langgraph_studio.png`**
   - LangGraph Studio workflow visualization showing conditional router edges and state transitions.

9. **`langsmith_trace.png`**
   - LangSmith execution trace showing latency, token usage, tool calls, and LLM structured outputs.
